# Python 学习练习集

这是你用于学习 Python 的练习仓库，包含基础语法、流程控制、函数相关练习等多个单文件示例。

目录结构（主要文件夹）：
- `python函数/`：函数的概念、参数、返回值、可变参数、lambda 等练习。
- `python基础1/`：数据类型、运算符、字符串等基础练习。
- `python基础2/`：条件分支、循环与综合练习。

快速开始
1. 建议创建并激活虚拟环境：

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# 或 PowerShell
.venv\Scripts\Activate.ps1
```

2. 安装推荐依赖：

```bash
pip install -r requirements.txt
```

3. 运行示例脚本：

```bash
python python基础1/比较运算符.py
```

最佳实践建议
- 将可重复的练习抽成函数或模块，避免把所有代码写在全局作用域。
- 给重要函数添加 `docstring`，便于复习和测试。
- 使用 `pytest` 为关键函数编写单元测试。
- 用 `black` 格式化代码、用 `flake8` 做静态检查。

下一步建议（可选）
- 将本仓库初始化为 Git 仓库并提交。添加 `.gitignore`（已包含）。
- 把部分练习合并成小项目（例如命令行待办列表、简单爬虫、或 Flask 微型应用），以练习模块化、I/O、错误处理与依赖管理。

## 学习计划（4 周，2 小时/天，周一到周五）

- 学习节奏：每天 2 小时 → 理论 30-40 分钟、练习 70-80 分钟、复盘 10-20 分钟。
- 工具准备：创建虚拟环境并安装 `requirements.txt` 中的工具。

### 第 1 周 — 打牢基础
- 周一：数据类型与运算符；练习小算术与字符串题目。
- 周二：条件分支；练习分级评分脚本。
- 周三：循环；练习九九乘法表与列表遍历。
- 周四：字符串处理；练习文本解析与词频统计。
- 周五：文件 I/O 与异常处理；练习读写日志。

### 第 2 周 — 函数、模块与测试
- 周一：函数与参数特性；把逻辑封装为函数。
- 周二：模块与包；把练习改为可导入模块。
- 周三：常用标准库（`os`, `json`, `datetime`）；练习配置读写。
- 周四：单元测试（`pytest`/`unittest`）；为函数写测试。
- 周五：代码格式化与静态检查（`black`, `flake8`）。

### 第 3 周 — 数据结构与面向对象
- 周一：列表与元组进阶（推导式、排序）。
- 周二：字典与集合；实现词频统计。
- 周三：面向对象基础；设计 `Task` 类示例。
- 周四：实现 CLI（`argparse`）的小程序（待办管理）。
- 周五：算法入门：查找/排序与复杂度概念。

### 第 4 周 — 小项目（选方向：Web 或 数据）
- 方向 A（Web，Flask）：实现简单留言板，表单处理、模板、模块化与测试。
- 方向 B（数据，Pandas）：加载/清洗/可视化 CSV 数据，封装分析流程并写报告。

### 交付物与衡量
- 每周至少一个 Git 提交与 1-3 个单元测试。
- 完成的小项目应包含 `README.md`、`requirements.txt` 与运行说明。
